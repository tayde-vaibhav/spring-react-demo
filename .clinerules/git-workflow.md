# Git Workflow
- Check `git status --short` before edits and before finishing.
- Do not discard, reset, stash, or overwrite pre-existing user changes without approval.
- Review `git diff` and `git diff --staged` before proposing a commit.
- Never commit secrets, credentials, generated build output, or local environment files.
- Do not commit, push, rebase, amend, or change remotes without explicit approval.
- Report changed files, tests run, tests not run, and any known risks.

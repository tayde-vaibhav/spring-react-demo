# Java / Spring Boot
- Follow the project's existing Java version, build tool, and package structure.
- Prefer constructor injection and clear separation of controller, service,
and persistence responsibilities.
- Validate request input and return appropriate HTTP status codes.
- Do not put secrets in source code or committed configuration.
- Add or update tests for behavior changes; run the project's test command.
- Avoid adding dependencies unless needed; explain why a new dependency is useful.
- Preserve existing API contracts unless the task explicitly changes them.

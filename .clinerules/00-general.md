# General Coding-Agent Rules
- Inspect the existing project structure and Git status before editing.
- Summarize the plan and identify likely files before making broad changes.
- Prefer small, focused, reversible changes over large rewrites.
- Preserve unrelated user changes; never overwrite them without approval.
- Do not expose, print, commit, or transmit secrets, tokens, or credentials.
- Do not run destructive commands, install system packages, or use sudo
without explicit approval.
- Do not commit, push, deploy, or change remote settings without explicit approval.
- Run relevant tests, builds, and linters; report commands and results honestly.
- If a requirement is ambiguous, ask a focused question rather than guessing.
- Explain assumptions, files changed, verification, and remaining risks.
